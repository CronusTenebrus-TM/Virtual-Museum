# 🏛️ Виртуальный музей вычислительной техники

Интерактивное десктопное приложение на движке Unity, представляющее собой виртуальную выставку, посвященную эволюции вычислительных технологий. Проект разработан в качестве демонстрационного учебного репозитория для портфолио.

---

## 🗺️ Структура экспозиции

Пространство музея разделено на 4 тематические зоны, каждая из которых отражает ключевую веху в истории развития вычислений:

1. **Домеханическая эра** — зарождение систем счета (узелковое письмо, абак, счёты).
2. **Механическая эра** — эпоха шестеренок и точной механики (арифмометры, аналитические машины).
3. **Электромеханическая эра** — автоматизация обработки данных (табулятор Холлерита, перфоленты и перфокарты).
4. **Электронная эра** — появление современных компьютеров и ЭВМ (легендарные машины ENIAC, Colossus, а также отечественные ретро-компьютеры «Корвет», «Счётмаш» и «Поиск»).

---

## ✨ Ключевые возможности и фичи

* **Интерактивное 3D-окружение:** Атмосферные залы музея с кастомными текстурами и мягким освещением.
* **Вращающиеся 3D-экспонаты:** Каждый исторический объект непрерывно вращается на своем постаменте для удобства кругового осмотра.
* **Кастомная система триггеров:** Реализована C#-логика отслеживания положения игрока. При приближении к экспонату активируется информационная плашка с исторической справкой.
* **Аудио-погружение:** Интегрированы звуки шагов при перемещении и расслабляющий фоновый эмбиент-саундтрек.
* **Пользовательский интерфейс (UI):** Лаконичные и легко читаемые адаптивные текстовые стенды.

## 🛠️ Стек технологий

* **Движок:** Unity (совместимо с версией 2018.4 LTS)
* **Язык программирования:** C#
* **Графический конвейер:** Built-in Render Pipeline (Standard)
* **Система ввода:** Unity Input Manager (классический WASD + мышь)

## 🚀 Быстрый запуск

### Запуск готового билда:
Если вы хотите протестировать проект без установки Unity, перейдите в раздел **[Releases](https://github.com)** в правой части страницы, скачайте актуальный ZIP-архив, распакуйте его и запустите исполняемый файл `.exe`.

### Сборка из исходного кода:
1. Клонируйте репозиторий на свой компьютер:
   ```bash
   git clone https://github.com
   ```
   *(Проект загружен без использования Git LFS, поэтому дополнительные утилиты для скачивания моделей не требуются).*
2. Откройте папку проекта через **Unity Hub** (рекомендуемая версия движка — 2018.x).
3. Откройте стартовую сцену в папке `Assets/Scenes/Virtual Museum.unity`.

## 🕹️ Управление в игре

* **WASD** — Перемещение игрока по залам
* **Мышь** — Обзор во все стороны
* **Приближение к объекту** — Автоматический вывод информационной плашки на экран
* **Esc** — Выход из приложения
